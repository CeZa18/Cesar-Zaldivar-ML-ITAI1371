## What I Did
Explored the classic Iris dataset using Python data analysis tools. I visualized
relationships between sepal and petal measurements across three flower species:
Iris Setosa, Iris Versicolor, and Iris Virginica.

## Dataset Overview
- **Samples:** 150 (50 per species)
- **Features:** 4 — sepal length (cm), sepal width (cm), petal length (cm), petal width (cm)
- **Classes:** 3 — Iris Setosa, Iris Versicolor, Iris Virginica

## Key Findings
- **Iris Setosa** tends to have the widest sepal measurements of the three species,
  while Versicolor and Virginica are very close in sepal width.
- **Iris Virginica** tends to present the longest sepal of the three species.
- **Iris Setosa** consistently presents the shortest sepal samples.
