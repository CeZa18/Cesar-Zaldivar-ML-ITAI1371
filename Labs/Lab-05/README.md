# Lab 05 — Model Evaluation & Metrics

## What I Did
Explored a range of evaluation metrics beyond accuracy, including confusion matrices, ROC curves, and the AUC score. Compared model performance using multiple metrics on the same dataset.

## What I Learned
- Why accuracy alone is misleading on imbalanced datasets
- How to interpret a confusion matrix and what true/false positives and negatives mean in practice
- How ROC-AUC measures a model's ability to discriminate between classes regardless of threshold

## Challenges
Interpreting the ROC curve intuitively — understanding that a curve closer to the top-left corner means better performance took some visualization practice.
