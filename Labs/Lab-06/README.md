# Lab 06 — Regression Models

## What I Did
Applied linear regression and polynomial regression to predict a continuous target variable. Evaluated models using Mean Squared Error (MSE) and R² score.

## What I Learned
- The difference between classification (discrete output) and regression (continuous output)
- How to interpret regression coefficients and what they tell you about feature impact
- How polynomial features can capture nonlinear relationships that linear models miss

## Challenges
Understanding when a model is overfitting vs. underfitting by comparing training and test scores — and what regularization does to address it.
