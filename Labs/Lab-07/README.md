# Lab 07 — Decision Trees & Ensemble Methods

## What I Did
Built and visualized a Decision Tree classifier, then compared it to ensemble approaches including Random Forest and Gradient Boosting to observe the performance improvements from combining multiple models.

## What I Learned
- How decision trees split data using information gain and Gini impurity
- Why individual decision trees overfit and how ensembles like Random Forest correct for this through bagging
- How feature importance scores from tree-based models can guide feature selection

## Challenges
Tuning `max_depth` to balance tree complexity against overfitting — too shallow underfits, too deep memorizes the training data.
