# Lab 04 — Supervised Learning & Classification

## What I Did
Trained my first classification model using scikit-learn, applied a train/test split, and evaluated results using accuracy and a classification report.

## What I Learned
- The supervised learning workflow: load data → split → train → predict → evaluate
- How `train_test_split` with `stratify=y` preserves class proportions
- How to read a classification report: precision, recall, F1-score, and support

## Challenges
Understanding the difference between precision and recall and when to prioritize one over the other in different real-world scenarios.
