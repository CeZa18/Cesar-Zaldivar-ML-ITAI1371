# Lab 08 — Support Vector Machines (SVM)

## What I Did
Trained Support Vector Machine classifiers with different kernels (linear, RBF) and explored how the choice of kernel and hyperparameters like `C` and `gamma` affect decision boundaries and model performance.

## What I Learned
- The concept of a hyperplane and how SVMs maximize the margin between classes
- How kernel functions transform data into higher-dimensional spaces to make non-linearly separable data separable
- Why LinearSVC is preferred for high-dimensional text classification due to speed and performance

## Challenges
Understanding the `C` parameter intuitively — higher C means less tolerance for misclassification but risks overfitting, while lower C allows more errors but generalizes better.
