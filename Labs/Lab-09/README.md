# Lab 09 — Unsupervised Learning & Clustering

## What I Did
Applied K-Means and hierarchical clustering to unlabeled datasets, used the elbow method to select the optimal number of clusters, and visualized cluster assignments using dimensionality reduction.

## What I Learned
- The key distinction between supervised learning (labeled data) and unsupervised learning (no labels)
- How K-Means iteratively assigns data points to centroids and refines cluster boundaries
- How to use the elbow method and silhouette score to evaluate clustering quality without ground truth labels

## Challenges
K-Means is sensitive to initialization and the choice of K — running it multiple times with different random seeds was necessary to get stable results.
